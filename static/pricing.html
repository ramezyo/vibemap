Common Questions

Do I need an API key for the free tier?

No. The free tier is completely open — no account, no API key, no credit card. Just start calling the API.

How does payment work right now?

We're in early access. Email hello@vibemap.live and we'll set you up with an API key and invoice via email. Stripe self-serve coming soon.

What's the difference between synthetic and real observations?

Every observation in the memory network is labeled by source. synthetic is simulation data, always clearly marked. human_reported means a human physically present contributed the observation. You can filter to any trust level you need.

Can I self-host?

Yes. The full stack is MIT-licensed and open source. docker-compose up -d and you have your own instance. You won't have the global network's accumulated memory, but you own everything.

What are the enterprise endpoints actually?

Two endpoints: GET /v1/enterprise/predictive-clusters (forecasts where high-energy social clusters will form in the next 4 hours) and GET /v1/enterprise/training-data (exports vibe-annotated spatial datasets in LGM-compatible format). Both require a Bearer token.
